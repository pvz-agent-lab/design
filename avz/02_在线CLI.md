# AvZ 在线 CLI

CLI 面向终端中的人和 agent，提供在线控制后端的命令入口。它不维护另一套 session、分支树或动作实现；SDK 与 CLI 指向同一个后端时，共享执行状态与错误语义。

## 能力面

- 创建、连接、查询和关闭 session，选择目标 worker；
- 观察稳定边界、提交单动作、显式推进与暂停；
- 创建和 checkout 分支，捕获/释放 checkpoint，查询恢复范围和实际策略；
- 从明确的持久化 root/frame 引用建立执行起点；
- 原生脚本的检查、构建、装载、启动、状态与停止；
- 轨迹录制、封存和可选视频任务，以及数据集工具的导出入口。

命令名称与参数待接口设计确定。数据集筛选和 manifest 解析由 trajectory-dataset 完成，CLI 组合入口不改变组件归属。离线命令只加载离线组件，不因同属一个工具就启动游戏或常驻后端。

## 结果与任务

stdout 输出机器可读结果，stderr 输出诊断；默认不依赖交互提示。结果保留请求身份、实际前后边界、实际完成量、失败/部分执行/未知状态与证据引用。稳定的响应 schema 需要版本，不将终端文本当成唯一契约。

CLI 进程退出不隐含关闭 session。长任务返回任务引用，后续命令可查询、等待或取消；退出、客户端超时和取消请求均不证明底层动作已经停止。结果未知时先查询并确认状态，不自动重发变更。

## 脚本工具链

`check/build/run` 是逻辑阶段，可以组合成便利命令。C++ 语法与类型检查调用编译器，额外 lint 调用已有工具；静态检查、构建、装载与运行结果分别报告，编译成功不证明策略能完成任务。

运行产物记录源码/构建身份、工具链与 SDK/Runtime 兼容版本。装载是否允许复用 Runtime 或需要重启由支持范围决定，不能默认热替换任意 DLL 后旧 checkpoint 仍有效。

单次即时操作直接使用在线动作接口，不生成临时 C++ 脚本。预约操作返回任务身份与调度信息，其最终执行回执另行关联；它不冒充当前边界上已完成的 commit。
